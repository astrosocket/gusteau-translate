## Installation
<!-- --8<-- [start:basic-install] -->
We're on [PyPI](https://pypi.org/project/gusteau-translate):

=== "pip"

    ``` bash
    pip install gusteau-translate
    ```
    
=== "uv"
    ``` bash
    uv pip install gusteau-translate
    ```

=== "pixi"
    ``` bash
    pixi add gusteau-translate --pypi
    ```
